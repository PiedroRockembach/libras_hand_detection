# MS-ASL (ASL)

- **Referência:** Vaezi Joze, H. R.; Koller, O. *MS-ASL: A Large-Scale Data Set and Benchmark for Understanding American Sign Language*. BMVC 2019 ([arXiv:1812.01053](https://arxiv.org/abs/1812.01053)). Projeto: [microsoft.com/en-us/research/project/ms-asl](https://www.microsoft.com/en-us/research/project/ms-asl/).
- **Licença / termos de uso:** **a verificar.** A página do projeto e a de download não exibem licença ([projeto](https://www.microsoft.com/en-us/research/project/ms-asl/); [download](https://www.microsoft.com/en-us/download/details.aspx?id=100121)).
- **Como obter:** `MS-ASL.zip` (1,9 MB, versão de agosto de 2019) no Microsoft Download Center ([download](https://www.microsoft.com/en-us/download/details.aspx?id=100121)). Pelo tamanho, deve conter só anotações e links, com os vídeos baixados da web; **a verificar**.
- **Conteúdo:** MS-ASL1000 tem 1.000 sinais, 222 sinalizadores e 25.513 amostras (24 h 39 min). Subconjuntos: MS-ASL100 (5.736 amostras, 189 sinalizadores), MS-ASL200 (9.719 / 196), MS-ASL500 (17.823 / 222) ([projeto](https://www.microsoft.com/en-us/research/project/ms-asl/)). Vídeos da web, RGB, resolução variada.
- **Protocolo oficial de avaliação:** **independente de sinalizador** ("signer-independent test") ([arXiv:1812.01053](https://arxiv.org/abs/1812.01053); [projeto](https://www.microsoft.com/en-us/research/project/ms-asl/)). Tamanhos das partes: **a verificar** no artigo.
- **Resultados de referência na literatura:** I3D é o *baseline* do artigo. Números: **a verificar** (não aparecem no resumo).
- **Status no projeto:** candidato (secundário).
- **Observações:** os vídeos vêm de *scraping*, sem consentimento explícito dos sinalizadores ([PopSign, NeurIPS 2023, §2.1](https://proceedings.neurips.cc/paper_files/paper/2023/file/00dada608b8db212ea7d9d92b24c68de-Paper-Datasets_and_Benchmarks.pdf)), e há links perdidos. Para pré-treino em ASL, o ASL Citizen é mais limpo.
